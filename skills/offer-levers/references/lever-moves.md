# Moves that raise each lever

Each move lists what it costs the owner. Pick moves that use what the owner already has before moves that need new work. Anything the owner doesn't already do is marked (new) in the offer.

## Result

| Move | What it does | Cost to the owner |
|---|---|---|
| Say the outcome in the buyer's words | Swaps "coaching" for what they actually want | None |
| Narrow to one buyer | "For first time landlords" beats "for anyone with property" | None, but fewer buyers see themselves in it |
| Narrow to the proven job | Lead with the result the owner has proof for | None |
| Tie it to why they care | Add the bigger reason ("so you can...") | None |
| Name the end state | What their week looks like after | None |
| Raise the scope | A bigger result (only if the owner can deliver and prove it) | High |

## Belief

| Move | What it does | Cost to the owner |
|---|---|---|
| Lead with the best real result | Moves proof from the bottom to the first lines | None |
| Name the client and the numbers (with permission) | Specific beats general | A message asking permission |
| Show proof from people like the buyer | Same type, same problem | None, if it exists |
| Show the method in steps | The buyer can see how it works | Low |
| Add one fair guarantee | Moves risk to the seller | Low to medium; cost it with `offer-guarantee` |
| Show the work | Before and after, a demo, a sample | Low |
| Collect proof fast | Ask recent buyers for a result and a sentence | Low, takes a week or two |
| Say who it's not for | Makes the fit claim more believable | None |

## Speed

| Move | What it does | Cost to the owner |
|---|---|---|
| Design a week one win | Something felt or used in the first 7 days | Low |
| Front load the most useful part | Give the plan, the fix or the setup first | Usually none, it's reordering |
| Show progress points | Name what they'll notice by week 2, week 4 | None |
| Shorten the first step | A start date this week, not next month | Low |
| Remove waiting on the buyer | Fewer forms and approvals before work starts | Low |

## Ease

| Move | What it does | Cost to the owner |
|---|---|---|
| Make decisions for them | A plan, a template, a default | Low |
| Add check ins | Someone notices when they slip | Medium (time per buyer) |
| Do one hard part for them | Write the first draft, set up the tool | Medium |
| Cut buyer homework | Fewer steps, shorter tasks | Low |
| Remove hassle | Easy cancellation, clear next steps, no surprise costs | Low |
| Done for you tier | The whole thing done for them | High; check capacity first |

## What not to do

- Don't fix Belief by adding features or bonuses. That adds stuff, not certainty.
- Don't raise the price to look premium while Result or Belief is below 7.
- Don't promise Speed the owner can't deliver. A missed week one win is worse than none.
- Don't raise Ease past the owner's capacity. A done for you offer that books them out is a new problem.
