# The guarantee

One guarantee, not several. It should remove the buyer's main fear, and the owner must be able to afford it.

## Pick the type

Ask these in order and stop at the first yes.

1. **Is the result mostly in the owner's control?** (a site delivered by a date, a report delivered, hours saved by a system the owner builds)
   Use an **outcome guarantee**: "If [specific result] isn't delivered by [date], we [refund / keep working free / pay a set amount]."
2. **Does the result depend on the buyer doing the work?** (fitness, coaching, courses, skills)
   Use a **do the work guarantee**: "Do [two clear actions] for [time]. If you don't [measurable result], we [remedy]." The actions are the buyer's side and must be easy to check. The result is the seller's side and must be something the buyer will feel (stronger, a skill learned, a first piece of work done), not just "you did the actions".
3. **Is the main fear just "what if I don't like it"?**
   Use a **no questions refund** for a short window: "Not for you in the first [14 or 30] days? Ask and get a full refund."
4. **Is a refund impossible because the work is used up straight away?** (custom builds, done for you work)
   Use a **keep going guarantee**: "If [result] isn't met, we keep working on it at no cost until it is" or a partial refund on the part not yet delivered.

## Aim it at the main fear

The guarantee should answer the fear behind the top objection. If the buyer's real fear is the final result and that result isn't fully in the owner's control (bookings, sales, weight), guarantee the nearest thing that is (the booking system live and tested, a measured time saving, strength on set lifts) and say plainly what isn't guaranteed.

## Wording rules

- Pattern: "If not [X] in [Y], we [Z]."
- Two conditions at most. Long fine print reads like a trap.
- The result must be measurable and fair. Never guarantee weight lost, income made, or anything the owner can't influence.
- Say exactly how to claim it.
- Cap the remedy: a refund, a set number of extra hours, or a set extra period. "We keep working until it's fixed" with no limit can eat a small business's whole month. Write the cap into the words.

## Cost it

Assume one buyer in ten claims it (a planning assumption, label it as such). Show the sum in one line: "per 10 sales, 1 claim costs [remedy] = [amount] (estimate)". Then say how many extra sales would cover it. If the owner can't afford it, shrink the remedy, not the honesty.
